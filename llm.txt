# FastSearch MCP v0.5.0

## Overview
FastSearch MCP is a FastMCP 3.2 server providing lightning-fast Windows file search via direct NTFS Master File Table (MFT) access. Zero indexing, zero caching. Features sampling, CodeMode, prompts, and skills.

## Architecture
- C++ Windows service (LocalSystem) → Named pipe `\\.\pipe\FastSearchMCP` → Python FastMCP 3.2 bridge → MCP client
- Ports: 10844 (web dashboard), 10845 (API + MCP HTTP)

## Key Tools
- `fastsearch_search(pattern, path, search_all, max_results)` — Name pattern search via NTFS MFT
- `fastsearch_search_advanced(...)` — MFT search with size/date/attribute filters
- `file_content_search(search_pattern, search_dir, ...)` — Regex content search in files
- `service_status` — Check FastSearch Windows service status
- `drive_inventory` — List all NTFS drives
- `analyze_disk_usage(path, max_depth)` — Disk space analysis
- `find_duplicate_files(directories, pattern, min_size)` — Duplicates by content hash
- `generate_file_hashes(paths, algorithm)` — File integrity verification

## FastMCP 3.2 Features
- Sampling: Tools can use `ctx: Context = None` → `ctx.sampling()` for client-side LLM
- CodeMode: Run with `--agentic` for discovery + execute meta-tools (`CodeMode().attach(mcp)`)
- Prompts: 3 `@mcp.prompt()` templates (search guide, disk analysis, troubleshooting)
- Skills: 3 `@mcp.skill()` definitions (recent files, cleanup, forensic audit)

## Dependencies
- fastmcp>=3.2.0,<4
- fastapi, pydantic, psutil, pywin32, httpx
